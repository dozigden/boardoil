About this experiment

The experimental renderer blends rounded card surrounds and bounded necks into one surface. Maximum neck limits cross-column connection thickness; merge reach controls stretching and separation. Connections use the shared vertical overlap, tilting when it runs out. Different slicks are drawn separately. Show outline reveals how the shapes meet. Timings cover JavaScript preparation and drawing commands, not browser paint or GPU time.

The comparison reproduces the current rounded-rectangle, bridge and blur recipe on this synthetic scene. It is not the full BoardOil renderer. This page uses no backend, account or saved board data.
